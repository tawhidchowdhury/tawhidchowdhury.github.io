# Tawhid Chowdhury — Portfolio

A responsive, buildless academic portfolio made with HTML, CSS, and a small amount of JavaScript.

## Preview

Open `index.html` in a browser. No package installation or build command is needed.

## Publish with GitHub Pages

1. Use the personal site repository named `tawhidchowdhury.github.io`.
2. Keep `index.html` at the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`.
4. Push updates to `main`; GitHub Pages will publish the static files.

## Update the site

- Replace the initials portrait in `index.html` with a compressed, square profile photo and meaningful alt text.
- Update the bio, research, selected projects, honors, and links in `index.html` as needed.
- The current academic CV is in `assets/docs/`.
- Change colors, spacing, and responsive rules in `assets/css/style.css`.
- The optional theme toggle and copyright year are handled by `assets/js/main.js`.

The visual direction is inspired by the compact academic portfolio layout in [Badhon's portfolio](https://badhon495.github.io/). This implementation uses its own HTML, CSS, and JavaScript.
